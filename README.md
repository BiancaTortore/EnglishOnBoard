# English on Board

App de inglés marítimo para oficiales de cubierta hispanohablantes.

- **Leer primero:** [`BIBLE.md`](BIBLE.md) (historia, personajes, temario y reglas).
- **Probar en la compu:** `npx serve .` y abrir http://localhost:3000
- **Publicar:** Cloudflare Pages, sin paso de build (output directory = raíz).
- **Audios:** `node tools/audio-script.mjs N` genera `audio/lNN/script.csv` para ElevenLabs.
